# HMDevTools — Antigravity Build Package

This package is the master product specification for building HMDevTools.

## Product
HMDevTools is a fast, privacy-conscious, professional collection of developer utilities. The initial release is a MERN + JavaScript web application.

## Primary goals
- Production-quality, working website — not a static mockup.
- Minimal, normal, professional UI.
- Light and dark modes.
- Fast perceived and actual performance.
- Client-side processing wherever practical.
- SEO-friendly tool landing pages.
- Reusable, data-driven tool architecture.
- Mobile, tablet and desktop responsive.
- Easy to add future tools without restructuring the app.

## Build instruction
Read `docs/MASTER_BUILD_PROMPT.md` completely before implementation. Treat it as the source of truth.

The demo logo in `brand/hmdevtools-demo-logo.svg` is temporary and must be used throughout the initial UI. Make branding easy to replace later.

## Suggested local commands
Frontend: npm run dev
Backend: npm run dev
Production: npm run build && npm start

Do not claim a feature works unless it is implemented and tested.
