# HMDevTools SEO Checklist

For every indexable tool page:
- Unique title
- Unique meta description
- Canonical
- H1
- Helpful introduction
- Functional tool
- How-to section
- Examples
- FAQ where useful
- Related tools
- Breadcrumbs
- Open Graph
- Structured data where appropriate
- Internal links

Technical:
- sitemap.xml
- robots.txt
- clean URLs
- fast pages
- responsive
- semantic HTML
- no duplicate title tags
- no accidental noindex
- correct canonical URLs

Never mass-generate thin pages purely for SEO.
