# Adding a New HMDevTools Tool

1. Create a tool implementation in the appropriate client tool folder.
2. Add its metadata to the centralized tool registry.
3. Add category and keywords.
4. Add SEO title/description.
5. Add examples.
6. Add FAQ.
7. Add related tools.
8. Declare processingMode accurately.
9. Add tests.
10. Verify mobile UI.
11. Verify copy/download/reset behavior.
12. Verify no sensitive input is sent to analytics.
