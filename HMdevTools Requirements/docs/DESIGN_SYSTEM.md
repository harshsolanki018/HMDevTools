# HMDevTools Design System

## Style
Minimal, professional, utility-first.

## Typography
Use a highly readable sans-serif system stack. Use monospace only for code, JSON, hashes, timestamps and technical output.

## Components
- Header
- Footer
- Button
- Input
- Textarea
- Search box
- Tool card
- Category card
- Badge
- Alert
- Tabs
- Code editor panel
- Output panel
- Breadcrumbs
- Modal
- Toast
- Pagination if needed

## Radius
Use restrained corner radii. Avoid pill-shaped UI except tags/status badges.

## Shadows
Use subtle shadows only where necessary.

## Animation
Fast, subtle transitions. Respect reduced motion.

## Spacing
Use a consistent spacing scale.

## Icons
Use one consistent icon family. Avoid mixing random icon styles.

## Code areas
Use clear monospace typography, line height, selectable text and obvious copy actions.
